Data and evaluation boundary

The U-Net notebook references absent Kaggle COCO 2017 paths. No local ground-truth mask set is included, so IoU, Dice, boundary accuracy, latency, or deployment performance is not claimed.

Preserved work

Three original notebooks and the Flask template remain unchanged. The Flask flow is documented as a temporary Colab/tunnel demonstration, not a deployable web application.

State

Documented preserved experiment. Restore authorised data, model environment, and labelled test masks before running or making a quality claim.

Responsible use

Preserve originals and disclose transformations. Do not treat an automatic mask as evidentiary output in medical, legal, surveillance, identity, or safety-critical work.
