1 · The label is not truth

A supplied class label can support an experiment in reproducing that corpus’s annotation pattern. It cannot establish whether a claim is true or whether a person or publisher is deceptive. Text classifiers can learn source, topic, author, boilerplate, or date artefacts instead of evidence quality.

Dataset label → text-classification experiment → never a universal truth or credibility judgement
Use boundary. This repository has no hidden fact-checking service, source-reputation lookup, web evidence retrieval, or human review queue.

3 · The recommended baseline

CSV → validate schema → headline + body → stratified split → TF-IDF unigram/bigram features → balanced logistic regression → precision / recall / F1

TF-IDF and logistic regression are chosen as a transparent first benchmark. The preserved neural notebook should be compared only under the same input text, split, and class-sensitive metrics.

DecisionWhy
Title + bodyThe project should model an article record, not silently discard the body.
Stratified splitPreserves label balance in training and holdout data.
Balanced weightsStops majority labels from dominating by default.
Precision / recall / F1Avoids an accuracy-only narrative.

4 · Original failures

The original notebook references an absent CSV, trains on title only despite building combined text, fails to persist lowercasing, joins stemmed tokens without spaces, and uses an unseeded non-stratified split. The original notebook remains preserved; the recommended implementation is separate and testable.

Two unit tests pin the required schema and title/body combination.

5 · Evaluation boundary

A random stratified holdout would measure only corpus-label replication. It would not prove transfer to a new publisher, a future news cycle, a new topic, or claim-level truth detection. Duplicate, source-grouped, and time-grouped checks are required before reporting any model score.

No performance metric is claimed. The original source CSV is absent, so full training has not been executed.

7 · Responsible-use limits

  • Labels are not universal truth judgements.
  • Text-only features cannot verify evidence or real-world claims.
  • No fairness, calibration, multilingual, adversarial, or drift study exists.
  • Do not use the project for moderation, reputation, employment, legal, medical, financial, education, or safety decisions.
