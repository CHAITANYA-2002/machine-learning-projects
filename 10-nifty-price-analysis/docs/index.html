NIFTY Closing-Price Analysis

Technical walkthrough for a chronological baseline that predicts a later NIFTY closing-price level using only earlier closing-price information.

1 · The future-leakage problem

The original notebook randomly mixed time-series rows. That means a 2023 date could train a model evaluated on 2010—a silent future-information leak. The corrected workflow asks the narrower, honest question: can the earliest data predict the final chronological holdout?

Historical closes → sort by Date → shift features one day → earliest 80% train → latest 20% test → MAE / RMSE / MAPE
This is not a trading strategy. It predicts a close-price level, not returns, signals, profits, or investment suitability.

Training covers 2008-01-29 through 2021-01-13. Testing begins strictly later, 2021-01-14 through 2023-09-04. The first 20 dates are unavailable to a 20-day prior-only average by definition.

4 · Baseline and result

A scaled linear regression is intentional: with three lagged price-level features, model complexity can memorise historical shapes without proving a durable mechanism.

MetricMeasured valueMeaning
MAE119.36Typical later-date miss in index points
RMSE157.86Large misses receive greater weight
MAPE0.71%Mean relative close-price error
Low MAPE does not imply profitable trading. A smooth, high-level series can make persistence-style forecasts look accurate while still failing at return direction, costs, volatility, and regime change.

6 · Limits and open item

  • One file, ending in September 2023.
  • One fixed holdout, not walk-forward retraining.
  • Price-only features; no volatility, news, macro, liquidity, or corporate-action model.
  • No transaction costs, position sizing, drawdown, or strategy backtest.
  • Model has no explicit regime detector.

Current state: verified educational baseline. Open next step: compare against naïve previous-close persistence under rolling walk-forward validation before adding model complexity.
