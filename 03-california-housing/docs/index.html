California House Price Predictor

Technical walkthrough for a reproducible baseline that estimates historical California district median house values—not current property valuations.

1 · The problem is not a valuation

The target is a 1990 census district median house value in units of $100,000. It is capped at $500,001, so this is a historical data exercise with a censored target—not an appraisal or a current-market forecast.

Interpretation boundary. A score on this target cannot estimate the price of a specific property, explain causality, or establish performance in a current market.

2 · System at a glance

California Housing → fixed 80/20 split → training-only imputer/scaler → 300-tree random forest → untouched test predictions → MAE / RMSE / R²

The sequence is a causal boundary, not a cosmetic pipeline. The split happens before preprocessing; otherwise the test districts could influence training statistics.

3 · Data contract

The project fetches the maintained scikit-learn dataset at runtime rather than committing a copied extract. Inputs are census-derived district means: income, house age, rooms, bedrooms, population, occupancy, latitude, and longitude. The data has no missing values in this execution; median imputation remains as a training-only guard if the input contract changes.

Important shape of the data: population ranges from 3 to 35,682 and average occupancy reaches 1,243.33, so extremes exist. Coordinates identify districts, not individual properties.

4 · Leakage boundary

20,640 rows → 16,512 training rows [fit] + 4,128 test rows [never fit] → predict once → report

The fixed random split is appropriate for a first tabular baseline, but it does not prove spatial transfer. Neighbouring districts can sit in different partitions. Spatially blocked validation is the stated next test before making a geographic-generalisation claim.

5 · Model and decisions

Decision Choice Reason
Estimator Random forest Captures nonlinear interactions without a deep-learning stack
Trees 300 Stable baseline without an impractical run time
Minimum leaf 2 Discourages one-row leaves
Imputation Median Robust future-input fallback
Seed 42 Repeatable split and model

Scaling is retained inside the pipeline to keep a reusable preprocessing interface, even though tree splits themselves are insensitive to scale.

6 · Measured result

Metric Value Meaning
MAE 0.326 About $32,600 typical absolute error
RMSE 0.504 About $50,400 when larger misses receive more weight
R² 0.806 80.6% of holdout variation captured
Do not convert R² into a valuation claim. It does not mean 80.6% of an individual home’s price is known, and it says nothing about error by geography or price band.

7 · Model reliance

Impurity-based forest importance ranks MedInc (0.535), AveOccup (0.138), latitude (0.088), longitude (0.088), and house age (0.053) first. This describes the fitted model’s splits, not causes. Income and location carry unobserved variables; permutation importance and geographic error slices remain open.

8 · The original failure

The first script did not run: it passed the dataset object as a train/test target, contained malformed Keras layers, misspelled metrics, and tried to predict from the training history. The rebuild uses small functions and three regression tests instead of hiding the failure behind a rewritten README.

Regression guards: repeatable split; one finite prediction per test row; known MAE/RMSE/R² arithmetic.

10 · Limitations and open item

  • 1990 data is not a live market.
  • The target is capped at $500,001.
  • Random holdout can leak spatial proximity.
  • District means cannot value individual homes.
  • Condition, schools, finance, zoning, and transaction timing are absent.
  • No fairness or geographic error-slice audit has been run.

Current state: verified local baseline. Open next step: spatially blocked validation and error analysis before any claim of regional transfer.
