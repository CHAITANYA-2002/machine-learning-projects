COVID-19 Chest X-Ray Classification

Technical walkthrough for a preserved TensorFlow CNN experiment. It is not a COVID case forecaster or diagnostic device.

Authorised X-ray folders → patient/site audit → train/validation/test split → augmentation → CNN → held-out clinical metrics

The hard constraint

Patient, hospital, scanner, and preprocessing leakage can produce a strong score without disease generalisation. A random image split is not sufficient evidence for medical use.

Data boundary

The expected third-party X-ray folder is empty in this checkout. No local training, clinical metric, or diagnostic claim is made.

Required evaluation

Sensitivity, specificity, precision, ROC-AUC, PR-AUC, calibration, confidence intervals, and site/device/subgroup evidence are required before a clinical-like claim can even be assessed.
