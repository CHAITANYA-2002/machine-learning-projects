Blue Book for Bulldozers

Technical walkthrough for the preserved historical Kaggle sale-price regression notebook. The repository folder is named “Bluetooth Sale Predictor”; the actual task is bulldozer auction pricing.

Historical auctions through 2011 → train → early 2012 validation → later 2012 test → RMSLE

The hard constraint

This is a time-ordered competition. Random splitting leaks future market information and invalidates the intended forecast-style evaluation.

Data boundary

The original Kaggle files are not stored here. Place authorised TrainAndValid.csv and Test.csv under data/bluebook-for-bulldozers/ before running the preserved notebook.

Metric

RMSLE measures multiplicative auction-price error and requires non-negative predictions. No score is claimed until the original data is restored and the workflow is rerun.
