02 · The task

Forecast-style validation: chronology is the hard constraint.

Historical salesup to 2011
Split by datefuture excluded
Fit on pastpreprocess + forest
Validate later2012 records
Measure RMSLEmultiplicative error

A random split would mix later market context into training. The project makes the cutoff explicit and verifies that every training date is earlier than every validation date.

03 · Data boundary

Historical auction records—not current appraisals.

The original work describes 412,698 training/validation records and 53 fields such as sale date, sale price, machine IDs, age, equipment configuration and location-like categories. Missingness and categorical cardinality are material. The CSV files are intentionally excluded from the repository.

05 · Legacy repair

Fix the root cause, not one missing column.

The legacy notebook converts train and test categories separately. Its test prediction first fails on a string category, then fails because test has 101 features while the model expects 102, then manually inserts auctioneerID_is_missing. That is brittle: any new category or missingness difference can alter the matrix again.

Old approach

Independent category codes, manual imputation, and hand-aligned columns.

Rebuilt approach

One fitted ColumnTransformer inside a pipeline; train-fitted ordinal codes keep high-cardinality data compact and map new categories to a safe sentinel.

06 · Metric

RMSLE measures relative-scale price error.

RMSLE = sqrt(mean((log1p(actual) - log1p(predicted))²))

It gives comparable treatment to proportionally similar mistakes at different price levels and is valid only for non-negative prices/predictions. The helper raises a clear error if this domain is violated.
